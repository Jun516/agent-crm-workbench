# 客赢智销：跨境客户经营场景入口

本项目在开源 AI Native CRM 底座上扩展。原有联系人、商机、授权工具、知识、Memory、Trace 与发送账本继续复用；本次新增任务级有界自精炼、精确工具授权和隐私/知识复验。没有改模型权重，也没有自动发布业务政策。

## 一条可以实际准备的业务任务

演示行业可以采用“B2B 日用品出口商的海外采购客户跟进”。这是教学配置示例，不表示已有真实客户或该行业生产验收。面向销售与客户运营，先聚焦“核对停滞原因和下一步”，不自动承诺价格、库存、交期或售后条件。

1. 用现有客户和商机页面选择一条演示记录，录入或关联已有沟通；真实个人信息按组织既有授权流程处理。
2. 在知识界面发布演示产品说明。WeKnora 使用运维绑定、组织启用和 Agent 授权来源交集，不能仅靠把网页链接贴给模型。
3. 在 Agent 配置中仅选择本次需要的查询工具；对应令牌会被工具清单进一步收窄。按实际模型配置设置有限预算，不在本示例里自动消费任何额度。
4. 工作台选择“只读检查”和具体业务对象。可用下面任务正文：

> 请核对这笔海外采购商机停滞的可能原因。先读取当前联系人、商机与近期沟通；产品说明只使用已发布且获准来源。将输出分为“工具确认的事实、仍待核实的解释、需要人工确认的下一步”。每项事实列来源和版本；历史摘要或画像不能覆盖当前记录。缺少已批准的价格、交期、优惠或发送许可时，明确未知，不向客户承诺，不改写业务字段，不发送消息。

5. 若需要比较不同调查路径，可显式开启本次新增“候选自精炼”。它最多按配置进行 1–2 轮、每轮 2–3 个候选；预算、失败或取消可能使实际数量更少。Probe 挑选有观察依据且结构合格的候选，父流程仍需要核实报告。
6. 在既有时间线查看子 Run、Probe、淘汰原因、赢家和低权威的方法提示。另从评测入口检查事实与语义质量；Probe 的覆盖分不是商业准确率。

## 第二条任务：复核后续经营安排

> 核对这位客户是否已有下一次跟进安排、是否存在重复计划或人工暂停。只描述现状与证据，提出由销售选择的下一步。客户回复“收到”、消息显示已发送、模型运行 completed 均不能当作已接受商业方案。

若要实际外发，必须走已有对应链路并核对批准与回执，不能把本次只读自精炼直接改成外发入口。原工作台某些提案生产环节仍需单独联调，不能借别的渠道路径声称整个闭环已验收。
